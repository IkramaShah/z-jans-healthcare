# Z-Jans Healthcare - Premium Pharmaceutical Website

A premium, product-focused pharmaceutical e-commerce website built with React, TypeScript, and Tailwind CSS. Features smooth animations, CSV-powered product management, and a professional enterprise design.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## ✨ Key Features

### Premium Product Experience
- **CSV-Powered Products**: Automated product loading from CSV file
- **Horizontal Scrolling Showcase**: Infinite smooth scroll with gradient fades
- **Product Filters**: Category-based filtering with smooth animations
- **Shop by Concern**: 12 health concern categories with premium imagery

### Enhanced User Experience
- **Lenis Smooth Scroll**: Premium Apple-like scrolling experience
- **Scroll Progress Indicator**: Real-time visual feedback
- **Micro-Interactions**: Hover effects, animations, and transitions
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop
